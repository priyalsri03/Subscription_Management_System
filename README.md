# Subscription Management System

A web-based Subscription Management System developed for managing products, subscription plans, discounts, and customer accounts.

## Current Features
- User Authentication (Signup/Login)
- Role-Based Access
- Product Management
- Product Variants
- Subscription Plan Management
- Discount Management
- Dashboard and Revenue Overview

## Tech Stack
- Python
- Flask
- SQLite
- HTML
- CSS
